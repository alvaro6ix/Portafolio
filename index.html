En backend: Node.js/Express, PHP/Laravel, Python, MySQL/PostgreSQL, Firebase y REST APIs. En frontend: React, JavaScript ES6+, HTML5/CSS3, Tailwind, Bootstrap y PWAs. En DevOps: VPS Linux (Hostinger), Docker, Cloudflare, DNS, subdominios y SSL. En integraciones: WhatsApp Business API, API de Gemini y de Claude, Telegram Bot API y webhooks. Y en IA: Claude, Gemini, Prompt Engineering, automatización de procesos y extracción de datos desde archivos y bases de datos. Mi día a día es VS Code y terminal.
